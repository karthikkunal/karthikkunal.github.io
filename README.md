# C. P. Karthik Portfolio

A responsive, editorial-style professional portfolio for GitHub Pages. The site
is built with static HTML, CSS and JavaScript; it does not require a framework,
build step or package installation.

## Pages

- Home
- About
- Projects
- Writing
- Contact

The homepage presents Karthik's work across cybersecurity, application and
network defense, security operations, cloud, IoT, AI research and software
engineering. Its animated 4D canvas responds to pointer movement and respects
reduced-motion preferences. The project explorer covers 27 distinct public
GitHub repositories and eight résumé-documented research and engineering builds,
with live search and category filters.
Every portfolio page keeps Check Point's live threat map fixed behind the
content, with a translucent readability layer and a link to its source on the
homepage.

Both public GitHub profiles and LinkedIn are linked throughout the site. The
LinkedIn profile does not expose a public banner for use here, so the homepage
uses its own original cybersecurity-inspired animation instead. The
downloadable résumé is available at
`assets/karthik-cp-karthik-resume.pdf`.

## Deploy on GitHub Pages

The repository is set up as a GitHub Pages site. Commit and push changes to the
configured publishing branch:

```bash
git add .
git commit -m "Refresh personal portfolio"
git push origin main
```
